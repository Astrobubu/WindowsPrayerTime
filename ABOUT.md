# About

Windows Prayer Time is a small Windows tray application created by Ahmad / Astrobubu for a practical daily need: keeping the next prayer time visible without turning it into a noisy or distracting app.

The app focuses on a quiet desktop workflow. Adhan reminders are intentionally subtle, while Iqamah reminders can be more noticeable when the PC is still active. The themed widget, manual layout editor, and per-text glow and shadow controls are built for people who want something functional but still personal on their desktop.
